# Plan: Refactoring Note Editor to RecyclerView

## Overview
Рефакторинг редактора заметок с одного EditText на RecyclerView с поддержкой 3 типов блоков:
- Текстовый абзац (TextBlock)
- Картинка (ImageBlock)
- Таблица (TableBlock)

## Фазы

### Фаза 1: Модель данных ✅ ЗАВЕРШЕНО
- [x] `ContentBlock.kt` — sealed class с 3 типами блоков
- [x] `ContentBlockParser.kt` — парсер текста в блоки и обратно
- [x] `ContentBlockTest.kt` — 21 тест
- [x] `ContentBlockParserTest.kt` — 25 тестов

### Фаза 2: RecyclerView Adapter + ViewHolder'ы
- [ ] `BlockViewHolder` — базовый абстрактный класс
- [ ] `TextBlockViewHolder` — ViewHolder для текстового блока (EditText)
- [ ] `ImageBlockViewHolder` — ViewHolder для картинки (ImageView + TextView caption)
- [ ] `TableBlockViewHolder` — ViewHolder для таблицы (RecyclerView с GridLayoutManager)
- [ ] `ContentBlockAdapter` — основной адаптер
- [ ] `BlockDiffCallback` — DiffUtil для обновления списка
